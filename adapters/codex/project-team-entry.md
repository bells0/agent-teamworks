# Project continuation entry

Append the block below to the target project's `AGENTS.md` during authorized team formation. Adapt it if the project uses a different state location; preserve existing instructions and avoid duplicate sections. It is a template for project adoption, not an instruction to form a team in this plugin repository.

```markdown
<!-- agent-teamworks:team:start -->
## Established Agent Teamworks team

For work assigned to this team, first read `.agent-teamworks/team.json`, the relevant role and work-item records, and applicable decisions and handoffs. The coordinator's current binding and recorded communication route are the entry for integrated team work.

Continue through the existing roster. Ordinary development and status requests do not trigger team formation. A new conversation must reconcile the current role binding before taking ownership; do not create a second coordinator or duplicate active owners.

Use the installed Agent Teamworks plugin when explicitly asked to build or adjust the team, or hand off and restore roles. Its bundled protocols govern team operation. Keep mutable team state in this project and preserve the project's authority and acceptance rules. If the plugin is unavailable, report that limitation and retain the existing records rather than recreating them.
<!-- agent-teamworks:team:end -->
```
