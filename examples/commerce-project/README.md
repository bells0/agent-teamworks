# Commerce Project Example

This is a fictional project used to demonstrate Agent Teamworks records. It does not describe the status, repository, people, or decisions of any real commerce product.

The example shows:

- one persistent five-role team;
- work decomposed by outcome and dependency, then routed into that roster;
- separate product acceptance, technical review, delivery readiness, and merge authorization states;
- separate product review advisor and verifier responsibilities;
- a completed builder-agent succession while the logical builder role remains stable;
- an implementer self-check that has passed while product acceptance and final independent review remain pending.

Start with the [operating model](../../framework/operating-model.md), then inspect the records under `.agent-teamworks/`.
